# claude_brain — project memory

Archives Claude Code sessions (`~/.claude/projects/**/*.jsonl`) into SQLite (`~/.local/share/claude-brain/brain.db`,
override `CLAUDE_BRAIN_DB`) for later recall. Stdlib-only Python (the hook needs no venv); `uv run pytest`.
Read code via `skeleton.py file::symbol`, not `cat`; the `Files:` lines below are the entry points.

- **Project naming is machine-independent.** `project_for` precedence: alias on git remote → alias on any cwd folder (deepest first) → repo name → `tmp` for temp dirs → last cwd folder. Names normalized (casefold, no accents, letters/digits, leading year dropped). `folder_aliases` keys: normalized folder or `github.com/owner/repo`. `sessions.repo`/`repo_root` resolved once per session after ingest (`repo_root=''` = checked, not a repo), kept if the folder vanishes.
  Files: `brain/db.py::project_for`, `brain/db.py::set_alias`, `brain/db.py::resolve_repos`, `brain/gitrepo.py::find_repo`, `brain/gitrepo.py::normalize_remote`
- **Ingestion is incremental and idempotent.** Byte offset per file in `files`; partial last line left for next run; `INSERT OR IGNORE` on message `uuid`. Lines starting `{"type":"` skipped unparsed except `ai-title`/`custom-title` (a custom title is never overwritten by an AI one).
  Files: `brain/ingest.py::ingest`, `brain/ingest.py::ingest_file`
- **Stored on purpose: prose in full, tool I/O clipped** (`TOOL_INPUT_CHARS`=300, `TOOL_RESULT_CHARS`=200). Roles `user`, `assistant`, `tool`, `summary` (compaction + `away_summary`). Dropped: thinking, `isMeta`, task notifications, injected tags. Subagent messages have `is_sidechain=1`, hidden by default. The DB answers "why/what was decided"; code is read from the repo.
  Files: `brain/ingest.py::extract`
- **Query API** = pure functions over a connection: search, recent, session (`--after` paging), projects, project, save_digest, alias. Digests are a lazy cache written by Claude; `covers_until_ts` limits the next report to newer sessions.
  Files: `brain/query.py`, `brain/query.py::save_digest`, `brain/query.py::project`
- **Two install paths, never both.** (1) Plugin: repo root = plugin root = marketplace (`.claude-plugin/plugin.json` name `brain`, `claude-*` is reserved; marketplace `aavzpy2023`). `hooks/hooks.json` runs `brain/hook.py [--sync]` on SessionStart + Stop (async) + SessionEnd; `skills/recall/SKILL.md` calls bare `claude-brain`; `commands/setup.md`, `commands/cloud.md` do what a plugin can't. (2) `install.py` for Windows/no plugins: renders the skill with `python bin/claude-brain`, merges exec-form hooks + permission + retention into settings.json, `--uninstall` reverses. `hook.py` logs to `ingest.log`, always exits 0.
  Files: `.claude-plugin/plugin.json`, `hooks/hooks.json`, `skills/recall/SKILL.md`, `bin/claude-brain`, `brain/cli.py`, `brain/install.py::render_skill`, `brain/install.py::merge_settings`
- **Cloud mirror (optional).** `sync.py` pushes SQLite → Neon after each ingest (Stop hook, async; offline = no-op): messages/digests by watermark in `sync_state`, sessions fully upserted, text redacted. Only sync needs psycopg, run as `uv run --no-project --with psycopg sync.py` — never a venv in the repo. claude.ai reads via the Neon MCP connector as `brain_reader` (SELECT-only). Many machines push to one mirror: digests keyed `origin`=`<host>:<local id>`; folder aliases sync both ways (last `updated_at` wins). `remote/claude_ai_instructions.md` is a template (`{{NEON_PROJECT_ID}}`), no personal ids in the repo.
  Files: `brain/sync.py::redact`, `brain/sync.py::uv_command`, `brain/sync.py::main`, `remote/schema.sql`, `remote/claude_ai_instructions.md`
- **Cloud schema only moves forward.** `remote/schema.sql` has `-- schema_version: N`; `ensure_schema` applies it (under `pg_advisory_xact_lock`) only when Neon's `brain_meta.schema_version` is lower, never when higher. Schema changes must bump N and stay additive. Rotating `reader_password` breaks the claude.ai connector: `cloud setup` sets it only if absent; only `cloud reader-password` rotates. `cloud connect` needs a TTY (getpass) and writes env 0600; `env_problems` only warns.
  Files: `brain/sync.py::ensure_schema`, `brain/sync.py::schema_plan`, `brain/sync.py::remote_status`, `brain/sync.py::write_env`, `brain/cli.py::cloud_connect`, `remote/schema.sql`
- **Reads go to Neon when the cloud is on.** `query.main` sends `READ_COMMANDS` to `brain/remote.py` (direct endpoint, read-only), same output via `query._run` plus `@host`. Exit `REMOTE_OFFLINE` (75) → local fallback; `--local` skips. Writes (`save-digest`, `alias`) are always local and reach Neon by sync. `sessions.host` exists only in Neon. Tests are isolated from real Neon by autouse fixture.
  Files: `brain/query.py::main`, `brain/query.py::_run`, `brain/remote.py`, `tests/conftest.py::no_real_cloud`
- **Search syntax is implemented twice and must stay identical.** Local `fts_query` (FTS5) and Neon `brain_tsquery`: words ANDed, last word stemmed (`STEM_SUFFIXES`, `STEM_MIN`) and prefix-matched (`PREFIX_MIN`), `OR`, "phrase", -exclude. Neon indexes `brain_plain(text)` to match unicode61 tokens. After any change compare hit counts on real data. Diagnostics on Neon use `SET LOCAL ROLE` in a transaction (the pooled endpoint leaks `SET ROLE`).
  Files: `brain/query.py::fts_query`, `brain/query.py::stem`, `remote/schema.sql`, `brain/sync.py::direct_url`
- **MCP server is opt-in per client.** `mcp_server.py` (mcp 2.x via uv) exposes read commands as read-only tools, redacted unless `--no-redact`. Clients point at `~/.local/share/claude-brain/mcp-launch.py`, which reads the plugin path from `root`, rewritten by `hook.py` via `mcp_setup.record_root()` each run so updates don't break configs. `mcp_setup` edits only the `claude-brain` entry of Claude Desktop's config (backup kept).
  Files: `brain/mcp_server.py`, `brain/mcp_launch.py`, `brain/mcp_setup.py::enable`, `brain/mcp_setup.py::record_root`
- **Session continuity is opt-in and must stay cheap.** One switch (`<state dir>/context` holds N) enables, all local, no network, errors swallowed: sync SessionStart hook (`context.py --hook`, 10 s) briefing = latest N sessions of the cwd's project, titles only; on `clear` a handoff card from the newest other transcript (ingested first); on `compact` a transcript pointer; resume gets nothing. Sync Stop hook (`--stop-hook`, 5 s) reads last main-chain `usage` and prints a user-only `systemMessage` when context enters a higher band (`context-warn`, default 120k, then every 40k; bands in `context-bands.json`, compaction re-arms).
  Files: `brain/context.py::hook_output`, `brain/context.py::handoff`, `brain/context.py::stop_output`, `brain/context.py::context_tokens`, `brain/ingest.py::ingest`, `brain/db.py::project_of_cwd`, `hooks/hooks.json`, `brain/install.py::commands`
- **`web` is a read-only viewer with a Cloud/Local switch (`?src=`).** `Source(name, conn, api, ph)` wraps SQLite or Neon; pages are written once over `Source.rows`. `ThreadingHTTPServer` on 127.0.0.1 only, fresh read-only connection per request, Host must be localhost, CSP `default-src 'none'`, every archived string through `html.escape` (`e`) before `render_text`. If `NEON_URL` is set and psycopg missing, `main` re-runs via `sync.uv_script`. Refuses without a TTY.
  Files: `brain/web.py::make_handler`, `brain/web.py::session_page`, `brain/web.py::render_text`, `brain/web.py::allowed_host`, `brain/cli.py::main`
- **`blame` matches files by repo-relative path anchored to the session's folder.** Candidates by substring, then per line: Edit/Write/MultiEdit/NotebookEdit path → edit; `[tool:Bash]` naming the file → shell; else mention. `is_same_file` needs the prefix to be the session's cwd or a parent (`lib/src/x.py` ≠ `src/x.py`). "Why" = last user message before the change; commits (`git log --follow`) go to the session active at commit time (+30 min).
  Files: `brain/blame.py::blame`, `brain/blame.py::is_same_file`, `brain/query.py::file_mentions`, `brain/remote.py::file_mentions`, `brain/db.py::project_of_cwd`
- **`stats` aggregates in the database, shapes in Python.** `stats_data` (in `query.py` and `remote.py`, same SQL modulo `instr`/`strpos` and placeholders) returns counts per UTC hour × role × project × source, tool calls by name, sessions in range; `stats.compute` builds local days, streaks, hour profile. Subagent messages excluded. Entry points call `brain.utf8_output()` (Windows pipes default to cp1252).
  Files: `brain/stats.py::compute`, `brain/query.py::stats_data`, `brain/remote.py::stats_data`, `brain/__init__.py::utf8_output`
- **Forgetting is tombstoned and synced.** `forget` deletes locally and records `forgotten(session_id, synced)`; `ingest_file` and `import_export` skip tombstoned ids. `sync_forgotten` runs before any push: deletes tombstones' rows in Neon, applies `pending_remote` ops (`redact` → `[REDACTED:manual]`, `project_digests`), pulls Neon's `forgotten` and drops those locally. Transcripts are deleted only with `--transcripts`.
  Files: `brain/forget.py::forget_sessions`, `brain/forget.py::redact_text`, `brain/sync.py::sync_forgotten`, `brain/ingest.py::ingest_file`, `remote/schema.sql`
- **`browse` = Datasette via uv, never bundled.** `cli.datasette_command` runs `uv tool run --from 'datasette>=0.65,<1'` (1.0 changes metadata format) with `brain/datasette.json` rewritten next to the DB, keyed by the DB file's stem. Blocks until Ctrl+C and refuses without a TTY: Claude must not run it.
  Files: `brain/cli.py::datasette_command`, `brain/datasette.json`
- **Markdown export** works over any read API, so with the cloud on it exports every device. Notes `<date>_<slug>_<id8>.md`, index `<project>.md`; writes only changed files, never deletes; redacts unless `--no-redact`.
  Files: `brain/export.py::export_project`, `brain/export.py::render_session`
- **claude.ai importer.** Official export → sessions with entrypoint `claude-ai`, session id = conversation uuid, `INSERT OR IGNORE` so re-imports only add. Pseudo cwd `claude.ai/<Project>` keeps the repo resolver off. Format is undocumented and the conversation→project link is absent in the real 2026 export; `load_export` opens only zips named conversations*/projects* (never `light_metadata`, it is login history); `--inspect` shows structure, not content.
  Files: `brain/importer.py::import_export`, `brain/importer.py::message_text`, `brain/importer.py::load_export`
- **README is the living doc.** Every user-visible change updates its Roadmap checkboxes and adds a Changelog entry in the same commit.
  Files: `README.md`
